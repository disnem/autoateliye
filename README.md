# АвтоАтелье — сайт-презентация

Статический сайт-презентация АвтоАтелье в Москве.

Сайт публикуется через GitHub Pages с помощью workflow в `.github/workflows/pages.yml`.

После включения GitHub Pages с источником **GitHub Actions** сайт будет доступен по адресу:

https://disnem.github.io/autoateliye/

Телефон, услуги и прайс перенесены из карточки организации в Яндекс Картах. Перед использованием как официального сайта уточните у владельца неоднозначные позиции прайса.
